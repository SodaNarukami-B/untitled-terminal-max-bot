### untitled max bot
---
**Concept**:
Reliable platform for creating and searching education materials.

**Why terminal**:
Repo called "untitled-**terminal**-max-bot" because doesn't using MAX-API. Why it doesn't? Because our team waiting for opening second hackathon tour where hackathon's authors provides API-tokens. Without API-tokens we cannot continue development, but i have another mindset and created mini MAX-API myself lol.

### Usage
---
Main package provides easy starting 1 of 3 modes:
- Client: imitates max-messenger app, sending commands and messages. 
- Server: Bot, that using http instead MAX-API.
- Filestorage: Mini file storage, created for database is not implemented.
